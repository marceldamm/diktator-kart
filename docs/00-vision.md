# Diktator Kart – Vision

## Projektidee

**Diktator Kart** ist ein browserbasiertes 3D-Kart-Rennspiel mit satirischem und stark schwarzhumorigem Stil.

Das grundlegende Spielprinzip orientiert sich an klassischen Arcade-Kart-Racern:

* Rundkurse
* mehrere Fahrer
* Bots
* Multiplayer
* Items
* Hindernisse
* Effekte
* unterschiedliche Fahrzeuge
* Streckenelemente
* Soundausgaben
* humoristische Ereignisse

Das Spiel soll einfach über einen modernen Webbrowser gestartet werden können.

Eine separate Installation als EXE soll nicht notwendig sein.

## Ziel

Das Projekt ist zunächst ein Fun-Projekt.

Es soll dennoch technisch sauber genug aufgebaut werden, dass daraus ein vollständig spielbares Browsergame entstehen kann.

Eine spätere öffentliche Veröffentlichung ist grundsätzlich vorgesehen.

## Spielerlebnis

Diktator Kart soll leicht zugänglich sein.

Der Spieler soll:

* die Website öffnen
* ein Rennen starten
* einen Fahrer auswählen
* gegen Bots oder andere Spieler antreten
* Items benutzen
* Streckenmechaniken erleben
* unmittelbar Spaß haben

Das Fahrgefühl soll klar im Vordergrund stehen.

## Grafikstil

Der geplante Stil ist:

**Modern N64**

Das bedeutet:

* Low-Poly-Modelle
* bewusst reduzierte Geometrie
* kleine Texturen
* kräftige Farben
* einfache Beleuchtung
* stilisierte Effekte
* Retro-Charme
* moderne Lesbarkeit und saubere Darstellung

Der Stil soll technisch leichtgewichtig und gleichzeitig optisch charakteristisch sein.

## Humor

Das Spiel soll stark satirisch und schwarzhumorig sein.

Ziel der Satire sind vor allem:

* Diktatoren
* autoritäre Systeme
* Propaganda
* Personenkult
* absurde politische Machtstrukturen
* staatliche Bürokratie
* manipulierte Wahlen
* Zensur
* Überwachung
* Größenwahn

Der Humor soll bewusst überzeichnet und absurd sein.

## Technische Leitidee

Das Spiel soll von Anfang an browserorientiert entwickelt werden.

Die Grafik wird auf dem Gerät des Spielers gerendert.

Ein späterer Server soll hauptsächlich verantwortlich sein für:

* Multiplayer
* Lobbys
* Rennzustand
* Bots
* Items
* Treffer
* Runden
* Platzierungen
* Synchronisation

## Entwicklungsstrategie

Das Projekt wird schrittweise aufgebaut.

Der erste Prototyp besteht nur aus:

* einer einfachen Teststrecke
* einem Platzhalter-Kart
* Kamera
* Gas
* Bremse
* Lenkung

Erst wenn das grundlegende Fahrgefühl funktioniert, werden weitere Systeme ergänzt.

## Zusammenarbeit

Das Projekt wird gemeinsam entwickelt.

GitHub dient als zentrale Plattform für:

* Quellcode
* Dokumentation
* Versionsverwaltung
* technische Entscheidungen
* Zusammenarbeit

KI-Unterstützung durch Codex ist ein wesentlicher Bestandteil des Entwicklungsprozesses.
